# Agent Matrix

Fifteen requested engineering responsibilities reuse the 24 existing agents.
This is a routing map, not a requirement to activate everyone. Linked agent
frontmatter is authoritative for tools; the table summarizes relevant grants.

## Common Contract

Every role receives requirements, current revision/content identity, bounded file
claims, dependencies, applicable instructions, acceptance criteria and a round
limit. Every result includes inspected files, actual evidence, findings with
severity, unverified items, a verdict and the next owner. **Definition of done
(DoD)** is the row's evidence plus this contract, not the role's confidence.

Tool shorthand: **R** = search/read; **W** = edit; **X** = general execute;
**O** = terminal-output inspection only; **Web** = available web tools;
**A** = native agent delegation. Questions are available across the roster;
todo/diagram tools on some builders do not grant more file ownership.
No role may invent evidence, read secrets, install dependencies without approval,
change permissions to evade a gate, or ship without separate authorization.
Only the Orchestrator delegates. Handoffs below mean return to it for routing.

## Path And Risk Defaults

This table covers each existing agent, not new roles. Paths are **maximum
eligible edit scope**, narrowed by its actual literal task claim; `none` means
no repository writes. All rows forbid edits outside their claim, secrets/private
data, and unauthorized state/package/customization changes. Review-only agents
may read relevant non-secret source but may not edit any path. QA/Performance
may write only approved isolated test artifacts, never implementation or tests.
Role tool grants above remain authoritative, not a filesystem sandbox.

Inputs for every row are the [task contract](task-contract.md), source/content
identity and relevant baseline. Outputs/checks are the role's evidence/DoD above
plus the [return envelope](agent-protocol.md). Escalation is always to the
Orchestrator for scope, conflicts, missing evidence or exhausted bounds; R5 goes
to the human. These ceilings are coordinator policy; schema 2 enforces the
[risk-role mapping](risk-model.md), not agent-specific execution ceilings or
automatic classification. Review depth is not limited by execution ceiling;
no role gains autonomous R5 authority.
